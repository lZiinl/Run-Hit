# RUN & HIT · 9회말 덱

지인에게 링크로 공유하는 야구 덱 빌딩 웹게임 시제품. 외부 서버·로그인·패키지 설치 없이 동작합니다. GitHub Pages가 정적 파일을 제공하고 경기 계산은 브라우저가 담당합니다.

## 실행

Node.js 24 설치 후 프로젝트 폴더에서:

```sh
npm start
```

현재 환경처럼 `npm`이 없는 경우 `node server.mjs`로 똑같이 실행할 수 있습니다. 테스트는 `node --test`, 빌드는 `node build.mjs`를 사용합니다.

http://127.0.0.1:4173 에 접속합니다. HTML 파일 더블클릭 대신 로컬 서버를 사용하세요.

```sh
npm test
npm run build
```

빌드 결과는 `dist/`입니다. 추가 의존성 설치는 없습니다. Google Fonts를 불러오지 못하면 시스템 글꼴을 사용합니다.

## GitHub에 배포

1. 본인 GitHub에 저장소를 만들고 이 프로젝트를 `main` 브랜치로 올립니다 (`dist`는 제외).
2. 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다.
3. **Actions → Deploy game to GitHub Pages → Run workflow**를 실행합니다. 이후 `main`에 push하면 테스트를 거쳐 자동 배포됩니다.
4. 배포 결과의 Pages 링크를 친구에게 공유합니다. 일반적인 주소는 `https://사용자명.github.io/저장소명/`입니다.

GitHub Pages는 방문자를 지인으로 제한하는 로그인 기능이 아닙니다. 이 버전은 공개 링크로 접속하는 게임입니다. 저장소 공개 범위에 따른 Pages 사용 가능 여부는 본인 GitHub 요금제에서 확인하세요. 아직 이 로컬 프로젝트에 연결된 GitHub 저장소나 배포 URL은 없습니다.

## 구현 범위

- 4팀 × 6명, 총 24명: 선수별 기본 확률과 6가지 타격 성향.
- 시작 영입과 스테이지 사이 영입: 후보 3명 중 선택 또는 건너뛰기.
- 선발 9명, 벤치 5명. 선수 두 명을 클릭해 타순/선발·벤치 교체.
- 선발 같은 팀 3명/5명 시너지, 직전 타자 및 득점권 조건 효과.
- 구단 효과 8종 중 3개를 제시, 중복 없이 선택.
- 5스테이지 × 2이닝. 목표 달성 즉시 통과, 실패/우승 결과 화면.
- 자동 공격, 1/2/4배속, 일시 정지, 연출 건너뛰기, 실시간 적용 확률.
- 실제 득점과 효과 보너스 구분, 최근 12개 타석 중계.
- 브라우저 최고 기록, 결과 텍스트 복사, 모바일 레이아웃.

## 규칙과 조정

`data.js`: 목표 득점, 타석 상한, 기본 속도, 선수·팀·구단 효과 데이터.
`engine.js`: 확률 및 효과 적용, 주자 이동, 이닝/경기 판정.
`app.js`: 영입·타순·화면·자동 진행·로컬 기록.

확률 증가는 아웃 확률을 감소시킵니다. 아웃이 0%가 되면 추가 증가를 제한합니다. 홈런 공장만 단타에서 홈런으로 확률을 옮깁니다. 팀의 확률 효과는 선발 전체에 적용합니다. 화면의 선수 카드는 기본 확률, 경기 화면은 다음 타자의 적용 확률입니다.

안타 시 모든 기존 주자가 타격 종류만큼 일괄 진루하며 표범 5명은 기존 주자만 추가 1루 진루합니다. 볼넷은 밀어내기만 적용합니다. 도루·병살·희생타·수비는 없습니다. 이닝당 최대 30타석이며 넘으면 이닝이 끝납니다. 직전 타자 강화는 이닝이 끝나면 사라집니다. 벤치가 가득 찼을 때 영입으로 교체된 기존 선발은 방출됩니다.

1배속 기본 간격은 타석당 2.4초입니다. 8~10분은 목표이며 선택 시간과 실제 타석 수에 따라 달라집니다. 난이도와 소요 시간은 지인 플레이테스트로 조정할 필요가 있습니다. 실행 중인 판은 새로고침하면 초기화되고 최고 기록만 남습니다. 기기 간 기록 공유·온라인 순위·저장 재개는 미구현입니다.

테스트는 밀어내기, 안타/홈런/추가 진루, 선발 시너지, 확률 합계, 다음 타자 강화, 이닝 종료, 목표 달성, 타석 상한, 시드 기반 300판 시뮬레이션을 확인합니다.
